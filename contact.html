Contact

TypeFlow is a static website with no backend. There is no live support channel, no ticketing system, no inbox monitored by a team.

If you found a bug, want to suggest a feature, or have a question about how the curriculum works, the best path is to check the FAQ first. Most common questions are answered there.

For everything else, you can reach the maintainer at hello@typeflow.example (replace example with the actual domain if this becomes a real deployment). Responses are not guaranteed, but genuine questions usually get an answer within a week.

TypeFlow does not collect analytics, run ads, or store your data anywhere except your own browser. If you want to report a privacy concern, that email still works.
